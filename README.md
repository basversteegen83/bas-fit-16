# Bas Fit 16

Persoonlijke mobile-first 16-weken fitness tracker.

- 3 krachttrainingen per week
- 2 eigen fit circuits
- core/buikspiertraining
- dagelijkse stappen en voeding
- voortgang voor gewicht, taille en oefenscores

Startwaarden: 91.5 kg / 102 cm taille.

De productie-app draait op Vercel. GitHub is vanaf nu de broncode/source of truth voor verdere ontwikkeling.
